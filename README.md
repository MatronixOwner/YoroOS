# YoroOS

Небольшая операционная система, написанная **полностью с нуля**: свой BIOS-загрузчик,
своё 32-битное ядро на Си, свой генератор загрузочного ISO. Никакого Linux внутри —
только наш код.

```

  \ \ / /__  _ __ ___  / _ \/ ___|
   \ V / _ \| '__/ _ \| | | \___ \
    | | (_) | | | (_) | |_| |___) |
    |_|\___/|_|  \___/ \___/|____/
  YoroOS version 0.1.0 (x86, custom kernel)
```

## Что умеет v0.1.0

- Загрузка с CD/ISO (BIOS, стандарт El Torito) — QEMU, VirtualBox, реальное железо
- Свой загрузчик: читает ядро с диска, включает A20, переходит в 32-битный protected mode
- Текстовый VGA-драйвер (80×25, цвета, скроллинг, аппаратный курсор)
- Драйвер PS/2-клавиатуры (Shift, Caps Lock, Ctrl, стрелки)
- Интерактивный шелл с историей команд (стрелки ↑/↓)
- Команды: `help`, `clear`, `echo`, `about`, `version`, `banner`, `cpu`
  (данные процессора через CPUID), `mem`, `date` (часы RTC), `color`, `reboot`, `shutdown`

## 📥 Для тестера: как запустить

Скачай `yoroos-v0.1.0.iso` со страницы **Releases** и выбери свой вариант:

### QEMU (проще всего)
```bash
qemu-system-i386 -cdrom yoroos-v0.1.0.iso -boot d -m 64
```

### VirtualBox
1. Создай ВМ: тип **Other → Other/Unknown (32-bit)**, RAM 64 МБ, жёсткий диск не обязателен.
2. В настройках ВМ: **Система** → убедись, что **EFI выключен**; порядок загрузки — сначала *Optical*.
3. **Носители** → подключи `yoroos-v0.1.0.iso` в оптический привод.
4. Старт!

### Реальное железо
Запиши ISO на диск или флешку (Ventoy / Rufus) и загрузись в режиме **Legacy/CSM**
(не UEFI). Нужна PS/2-клавиатура или включённый *Legacy USB Support* в BIOS.

- [ ] Стрелки ↑/↓ листают историю? `Ctrl+L` чистит экран? `Ctrl+C` отменяет строку?
- [ ] `shutdown` выключает машину? `reboot` перезагружает?

## 🛠 Сборка из исходников

Нужны только `gcc`, `binutils` и `python3` — ни GRUB, ни xorriso, ни nasm:

```bash
make          # соберёт build/yoroos.iso и сам проверит его структуру
make run      # запустить в QEMU (если установлен)
```

Проверка загрузки без QEMU (полноценная эмуляция загрузки и шелла через Unicorn):

```bash
pip install unicorn
python3 tools/emutest.py build/yoroos.iso
```

## 🗂 Структура проекта

```
boot/boot.S       — BIOS-загрузчик (16-бит → protected mode)
kernel/entry.S    — точка входа ядра
kernel/*.c        — ядро: VGA, клавиатура, RTC, CPUID, шелл
include/*.h       — заголовки
linker.ld         — скрипт компоновки ядра (загрузка по 0x10000)
tools/mkiso.py    — собственный генератор ISO9660 + El Torito
tools/verify_iso.py — проверка структуры собранного ISO
tools/emutest.py  — сквозной тест загрузки в эмуляторе Unicorn
```
