# YoroOS

## Текущее направление: YoroOS Desktop

Основой настольной версии снова выбран **Debian 13 + Linux**. Поверх него —
оболочка KDE Plasma с оформлением YoroOS и собственные приложения. Linux,
KDE, Qt и другие необходимые компоненты остаются внутри системы; это не ОС на
собственном ядре. Первый образ — Live, без установки и сохранения изменений.
Сборка и тестирование: [desktop/README.md](desktop/README.md).

### Live-образ для тестирования

[Скачать обновлённый ISO](https://github.com/MatronixOwner/YoroOS/releases/download/desktop-debian13-live-947fe759c0e9/yoroos-debian13-live-947fe759c0e9-amd64.iso) · [выпуск и SHA256SUMS](https://github.com/MatronixOwner/YoroOS/releases/tag/desktop-debian13-live-947fe759c0e9)

В Hyper-V создайте ВМ **поколения 2**, выделите не менее 4 ГБ ОЗУ,
подключите ISO к DVD-приводу, поставьте его первым в порядке загрузки и для
первого теста выключите Secure Boot. Для сети подключите виртуальный
коммутатор. Запуск Live-сессии автоматический; если появится вход, пользователь
`yoro`, пароль `live`. Данные после выключения не сохраняются.

UEFI, Live-сессия и отображение тестовой страницы Matronix проверены в QEMU;
конкретно этот образ ещё не проверен в Hyper-V. На первом входе показывается
экран приветствия. Голосовой MP3 в образ не включён; подробности и импорт —
[приветствие YoroOS](docs/welcome-audio.md). Экспериментальное нативное ядро
и YoroFS в Live-образ не встроены.

Нативное ядро и его отдельный экспериментальный ISO сохранены в репозитории;
они не встроены в этот Linux-образ. Далее описан **исторический нативный
прототип**, а не текущая настольная версия.

Небольшая операционная система, написанная **полностью с нуля**: свой загрузчик,
своё ядро, свой генератор загрузочного ISO. Никакого Linux внутри — только наш код.

ISO **гибридный**: один и тот же образ загружается и на старых машинах через **BIOS**,
и на современных через **UEFI** (в том числе **Hyper-V поколения 2**).

```
  __   __               ___  ____
  \ \ / /__  _ __ ___  / _ \/ ___|
   \ V / _ \| '__/ _ \| | | \___ \
    | | (_) | | | (_) | |_| |___) |
    |_|\___/|_|  \___/ \___/|____/
  YoroOS version 0.2.0
```

## Что умеет v0.2.0

- **Две загрузки в одном ISO** (El Torito BIOS + UEFI `BOOTX64.EFI`)
- **BIOS-путь:** свой 16-битный загрузчик → 32-битное ядро на Си, VGA-текст, PS/2-клавиатура
- **UEFI-путь:** фирменное EFI-приложение — тот же шелл на консоли прошивки
  (на Hyper-V Gen2 нет ни VGA-текста, ни PS/2, поэтому так надо)
- Шелл с историей команд (стрелки ↑/↓, `Ctrl+C`, `Ctrl+L`)
- Команды: `help`, `clear`, `echo`, `about`, `version`, `banner`, `cpu` (CPUID),
  `mem`, `date`, `color`, `reboot`, `shutdown` (+ `exit` в UEFI-версии)

## 📥 Для тестера: как запустить

Файл: **`yoroos-v0.2.0.iso`** (лежит в папке [`dist/`](dist/) этого репозитория).

### Hyper-V, поколение 2 ⭐
1. **Выключи** виртуальную машину.
2. **Параметры → Безопасность** → **сними галочку «Включить безопасную загрузку»**
   (Secure Boot). Наш загрузчик не подписан Microsoft — с включённой безопасной
   загрузкой прошивка покажет ошибку про недопустимый хэш (DB) и не стартует.
3. **Параметры → Контроллер SCSI → DVD-дисковод** → файл образа: `yoroos-v0.2.0.iso`.
4. **Параметры → Встроенное ПО (Прошивка)**: DVD-дисковод — **первый** в порядке загрузки.
5. Запуск! Должен появиться логотип и приглашение `yoro@YoroOS:~$`.
   Команда `exit` вернёт в меню прошивки, `shutdown` выключит ВМ.

### Hyper-V, поколение 1
Там BIOS — просто подключи ISO к IDE DVD и поставь CD первым в порядке загрузки (BIOS).

### QEMU
```bash
qemu-system-i386 -cdrom yoroos-v0.2.0.iso -boot d -m 64        # BIOS-режим
qemu-system-x86_64 -bios OVMF.fd -cdrom yoroos-v0.2.0.iso -m 64 # UEFI-режим
```

### VirtualBox
ВМ **Other/Unknown (64-bit)**, RAM 64 МБ. Работает в обоих режимах:
EFI выключен → BIOS-ядро; **Система → Включить EFI** → UEFI-версия.
ISO подключить в оптический привод, загрузка сначала с Optical.

### Реальное железо
ISO на диск/флешку (Ventoy / Rufus). BIOS/Legacy — ядро, UEFI (Secure Boot выкл.) — EFI-версия.

прошивки ВМ (у Hyper-V это UTC хоста).

## 🖥 YoroOS Desktop — прежний Linux-прототип

Историческая версия; дальнейшее развитие направлено на нативную систему:

- **50% Linux:** дистрибутив на **Debian 13 + KDE Plasma** (красивый и плавный
  интерфейс), **Matronix Browser** (свой браузер), **Wine** для Windows-программ.
  Чужие пользовательские программы из образа вырезаны — только свои.
- **50% своё:** собственный набор приложений на Qt6 (нативное ядро не встроено в этот образ): **Блокнот, Центр Настроек,
  Медиаплеер, Файлы, Консоль, Мой компьютер, Корзина, Калькулятор, Paint**
  + свои иконки, градиентные обои и фирменная панель «Пуск» (папка [`desktop/`](desktop/)).

Полный ISO дистрибутива собирается скриптом [`distro/build-iso.sh`](distro/build-iso.sh)
(live-build) или в GitHub Actions — workflow **“Build YoroOS Desktop ISO (Linux)”**,
готовый образ лежит в артефактах запуска. Подробнее: [`desktop/README.md`](desktop/README.md).

## 🛠 Сборка из исходников

Нужны только `gcc`, `binutils` и `python3` — ни GRUB, ни xorriso, ни nasm, ни gnu-efi:

```bash
make          # build/yoroos.iso + автоматическая проверка структуры
make run      # запуск в QEMU (BIOS), если установлен
```

Проверка BIOS-загрузки без QEMU (эмуляция всей цепочки через Unicorn):

```bash
pip install unicorn
python3 tools/emutest.py build/yoroos.iso
```

## 🗂 Структура проекта

```
boot/boot.S          — BIOS-загрузчик (16-бит → protected mode)
kernel/*             — 32-битное ядро: VGA, клавиатура, RTC, CPUID, шелл
efi/efi_main.c       — UEFI-приложение BOOTX64.EFI (тот же шелл на консоли UEFI)
efi/efi.h, efi.lds   — минимальные UEFI-определения и скрипт компоновки
tools/mkiso.py       — собственный генератор ISO9660 + El Torito (BIOS+UEFI)
tools/mkefiboot.py   — сборщик FAT12-образа с \EFI\BOOT\BOOTX64.EFI
tools/verify_iso.py  — проверка ISO: каталог El Torito, FAT, заголовки PE
tools/emutest.py     — сквозной тест BIOS-загрузки в эмуляторе Unicorn
```
