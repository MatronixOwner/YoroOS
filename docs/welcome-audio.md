# Приветствие YoroOS

При первом входе пользователя запускается экран приветствия. Флаг
`~/.config/yoroos/welcome-seen` не даёт повторять его при каждом входе.
В Live-образе домашний каталог временный, поэтому экран снова появляется при
каждой загрузке. В настройках его можно открыть повторно и отключить звук.

Фирменный MP3 пока не включён в образ: генерация и скачивание с Fish Audio в
этом окружении недоступны, а права на распространение выбранной записи не
подтверждены. Подходящий вариант для прослушивания — спокойный русскоязычный
голос [Russian от Laja Kakaj](https://fish.audio/m/8690e141497b46f2a82f5686e9701b97/).
Fish Audio указывает, что бесплатный тариф предназначен для личного пользования;
перед публикацией образа с записью необходимо проверить условия конкретного
тарифа и голоса. Рекомендованный текст: «Добро пожаловать в YoroOS. Всё готово
к работе. Пусть этот день начнётся с вдохновения.»

В **Настройки → Приветствие** можно выбрать и прослушать MP3, на использование
которого есть права. Файл копируется в `~/.local/share/yoroos/welcome.mp3`;
он тоже исчезает при выключении Live-системы. При создании распространяемого
образа с лицензированной записью её можно положить в
`desktop/sounds/welcome.mp3`, после чего сборщик включит файл в образ.
