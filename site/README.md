# Сайт MatroOS

Статический сайт. Публикуется GitHub Actions из каталога `site/` на GitHub Pages.
На странице нет сторонних счетчиков или серверной части. Браузер читает
публичный API GitHub Releases и показывает ISO-ресурсы, сортируя их по дате
публикации. Черновики и чужие ссылки не показываются. При ошибке сети или
лимите API остаётся прямая ссылка на известный опубликованный ISO и ссылка на
все релизы. Чтобы следующий образ появился автоматически, его нужно добавить
к публичному GitHub Release в этом репозитории как `.iso`.

Предварительный URL после успешной настройки Pages:
https://matronixowner.github.io/MatroOS/ . Источник Pages: GitHub Actions;
рабочий процесс запускается из активной ветки и использует среду `matroos-pages`.
Настройка Pages может потребовать права администратора репозитория.
Работа GitHub Pages не имеет гарантии бессрочности; сайт не зависит от
локального сервера и будет доступен, пока репозиторий и Pages остаются доступными.

Проверка: `node --test tests/test_site.mjs`; браузерная проверка выполняется в
workflow. Для локального просмотра: `python3 -m http.server 4173 -d site`.
