# MatroOS Game — экспериментальная сборка

Отдельное игровое издание на основе **Bazzite KDE / Fedora Atomic (bootc)**,
не замена существующего Debian Live-образа MatroOS. За основу берётся
`ghcr.io/ublue-os/bazzite:stable`. Bazzite сохраняет собственные компоненты,
включая Steam, Lutris и игровой стек; совместимость с конкретными играми,
античитом и видеодрайверами нужно проверять отдельно. На Hyper-V GPU может
быть программным; это не показатель производительности на реальном ПК.

Фирменные приложения MatroOS и Matronix Browser добавляются к основе, а не
заменяют Bazzite. Для новых профилей используется одна нижняя панель с
центральными значками, логотип MatroOS, выбранные Kora и Bibata и собственные
обои; оформление вдохновлено Windows 11, но не использует его логотипы. Уже
существующие конфигурации панелей пользователя не перезаписываются при входе.

На данном этапе это **сборочная конфигурация**, а не опубликованный ISO.
Работоспособность установки, игр, обновлений, Secure Boot, собственных
приложений и Hyper-V должна быть проверена до предложения пользователям.
Образ Bazzite обновляется через bootc/OCI, а не `apt`; подписывание, публичная
регистрация своего образа и совместимость цепочки обновлений ещё требуют
настройки. Не следует устанавливать экспериментальную сборку на основной диск
или вместо текущей ОС без отдельной проверки и резервной копии.
