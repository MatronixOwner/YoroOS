# YoroOS Desktop — тестовая Linux-редакция

YoroOS Desktop строится на **Debian 13, ядре Linux и KDE Plasma**. Мы
настраиваем оболочку и набор своих приложений, а необходимые сторонние системные
компоненты, драйверы, библиотеки и темы остаются. Отдельное экспериментальное
собственное ядро YoroOS в этот ISO не входит.

## Пробный образ

* UEFI Live для тестирования в виртуальной машине Hyper-V поколения 2;
  установщика на диск и постоянного сохранения данных пока нет.
* Ядро Debian, Live Boot, X11, Plasma и SDDM, сеть и звук; модули
  Hyper-V storage, network, mouse и keyboard перечислены для initramfs.
* Live-пользователь `yoro`, вход в Plasma X11 настроен автоматически.
  Не используйте этот открытый тестовый режим для личных данных.
* Yoro-приложения: файлы, блокнот, настройки, медиа, консоль, компьютер,
  корзина, калькулятор, Paint; Matronix Browser из репозитория владельца.
  Поддержка запуска приложений Windows в этой сборке не заявляется.
* Графический запуск и оборудование Hyper-V проверяются пользователем в ВМ.
  Успешная сборка и проверка в QEMU не подтверждают работу Hyper-V.
* Свои значки приложений и обои. CI-образ включает выбранные иконки Colloid и
  курсор Bibata Modern Ice (GPL-3.0); при локальной сборке без переменной
  `YORO_THEME_INPUT_DIR` используются стандартные иконки и курсор.
* Необязательные nano, htop, git, curl не запрашиваются явно. Системные
  приложения, попавшие как зависимости, скрываются в меню через XDG-override,
  а не удаляются; их наличие и видимость в других местах не исключены.

## Hyper-V

Создайте ВМ поколения 2: 4 ГБ RAM (8 ГБ комфортнее для браузера), 2 виртуальных
ядра, ISO первым в порядке загрузки. Secure Boot лучше выключить для первого
теста: корректность подписанной загрузки именно этого образа не подтверждена.
При тестировании Live-образу виртуальный жёсткий диск не нужен. Всё сделанное
в Live-сессии пропадает после выключения.

## Сборка

```sh
sudo apt install live-build xorriso squashfs-tools grub-pc-bin grub-efi-amd64-bin
sudo ./distro/build-iso.sh out
python3 -m unittest discover -s tests -p 'test_desktop_branding.py'
python3 -m unittest discover -s tests -p 'test_build_staging.py'
```

Для полного оформления используются исходники тем в `YORO_THEME_INPUT_DIR`;
их подготовку демонстрирует workflow `Build YoroOS Desktop ISO (Linux)` на GitHub. `out/` содержит ISO
и его SHA-256. При первой загрузке проверяйте видимый рабочий стол, мышь,
клавиатуру, панель и запуск Matronix Browser; при проблеме пришлите скриншот.
