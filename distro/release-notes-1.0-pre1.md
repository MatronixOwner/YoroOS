# 🧪 YoroOS Desktop 1.0 — Pre-release 1

Первый публичный пре-релиз настольной редакции **YoroOS**. Это тестовая сборка:
ищем баги, собираем впечатления, полируем.

## Что это

Гибридная система «50/50»:

- **Основа:** Debian 13 + KDE Plasma (надёжность и плавный рабочий стол),
  из образа вырезаны все чужие пользовательские программы;
- **Сверху — полностью свои приложения Matronix/Yoro.**

## Состав

| Приложение | Что умеет |
|---|---|
| 🌐 **Matronix Browser** | Браузер автора из репозитория [Matronix_Browser](https://github.com/MatronixOwner/Matronix_Browser) (PySide6/Qt WebEngine): вкладки, история, загрузки, пароли, настройки. Браузер по умолчанию |
| 📝 Блокнот | Редактор текста |
| 📁 Файлы | Файловый менеджер (удаление — в настоящую корзину) |
| 🎬 Медиа | Аудио/видео плеер с плейлистом |
| 🎨 Paint | Рисование, сохранение PNG |
| 🧮 Калькулятор | С выражениями и скобками |
| 🖥 Консоль | Команды bash + `yoro`, `yoro-apps`, `yoro-help` |
| 💻 Мой компьютер | Диски и папки |
| 🗑 Корзина | Восстановить / удалить / очистить |
| ⚙️ Центр Настроек | Цвет акцента, **сгенерированные градиентные обои**, положение и высота панели «Пуск», **библиотеки кастомизации**: Hyprland, Wayfire, Picom, Eww (установка + стартовые конфиги) |

Плюс: фирменная панель с логотипом Yoro, свой набор иконок, Wine для
Windows-программ, русская локаль, раскладки RU/US.

## Скачивание

- `yoroos-desktop-1.0-pre1-amd64.iso` (~2 ГБ) — образ диска;
- `SHA256SUMS.txt` — контрольная сумма (проверка: `sha256sum -c SHA256SUMS.txt`).

## Как запустить

**Hyper-V (поколение 2):** RAM 4–8 ГБ, ISO в SCSI-DVD первым в порядке загрузки,
шаблон безопасной загрузки **«Microsoft UEFI Certificate Authority»** (или Secure
Boot выключен).

**VirtualBox:** ВМ 64-bit, включён EFI, ISO в оптическом приводе.
**QEMU:** `qemu-system-x86_64 -bios OVMF.fd -cdrom yoroos-desktop-1.0-pre1-amd64.iso -m 4096`

Режим — **Live** (установки на диск пока нет), пользователь `yoro`, автовход,
sudo без пароля.

## Известные недочёты (пре-релиз же!)

- Приложения впервые запускаются «вживую» — возможны падения; журнал Matronix
  Browser: `~/Matronix/logs/matronix.log`;
- Собственное ядро *YoroOS Core* в этот ISO ещё не встроено вторым пунктом
  загрузки (в планах);
- Установщика на жёсткий диск пока нет (в планах — Calamares).
